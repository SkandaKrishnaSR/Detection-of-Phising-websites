# 🛡️ Detection of Phishing Websites

## 📘 Description

This project is designed to detect phishing websites using Machine Learning techniques. The system analyzes different URL-based features to classify a website as **legitimate or phishing**. It helps identify potentially malicious websites that may attempt to steal sensitive user information.

The web application is developed using **Flask** and integrates a **Random Forest Classifier** trained on a CSV dataset containing URL features. Users can enter a website URL, and the system processes its characteristics and provides a phishing or legitimate classification.

## ⚙️ Technologies Used

* **Python** – Core programming language
* **Flask** – Backend web framework
* **Machine Learning** – Random Forest Classifier
* **HTML & CSS** – User interface
* **CSV Dataset** – Training and testing data

## 🎯 Key Features

* Simple and user-friendly interface
* URL-based phishing detection
* Machine learning-based classification
* Real-time prediction of website status
* Easy to extend with additional URL features
